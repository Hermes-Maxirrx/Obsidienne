# Java et architecture — parcours

Les dépôts de l'enseignant (sept supports de TP) ne sont que les sources pédagogiques, **pas nos dépôts ni un historique personnel**. [[Hexa Java]] est un projet pédagogique **indépendant**, non un sixième TP.

2. **Frontière Web et données** : [[Spring - HTTP DTO validation erreurs]] → [[Persistance - JPA Liquibase PostgreSQL]]. Continuer TP4 → TP5.
3. **Méthode** : [[Tests - TDD et Cucumber]] et [[TDD - revision double boucle]] : tests unitaires puis scénarios HTTP.
4. **Transfert indépendant** : [[Architecture - hexagonale et ports]] → [[Metier - commandes stocks transactions]] → [[Fiabilite - outbox inbox jobs]] ; parcourir [[Hexa Java]].
