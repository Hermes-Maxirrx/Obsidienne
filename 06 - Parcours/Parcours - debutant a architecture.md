# Parcours — du débutant à l'architecture

Ne cherche pas à tout apprendre d'un coup. Avance dans cet ordre en choisissant les branches utiles à ton objectif.

## Étape 1 : comprendre ce que l'application traverse

[[Reseau - requete DNS TCP TLS HTTP]] → [[Reseau - IP ports VNet et acces]] → [[Donnees - SQL et migrations]]. Question témoin : que se passe-t-il entre un navigateur, une API et une base de données ?

## Étape 2 : lire et tester un programme

[[Java - objets et identité ISBN]] → [[Java - exceptions et collections]] → [[Tests - TDD et Cucumber]]. Regarde d'abord [[Java - revision Spring Boot]], puis [[TDD - revision double boucle]]. La progression Java du professeur est reconstruite pour révision, pas un historique de tes anciens TP.

## Étape 3 : relier interface, API et données

Côté interface : [[React - etat rendu reducer contexte]] → [[React - effets asynchrone annulation]] → [[React - formulaires accessibilite]]. Côté service : [[Spring - HTTP DTO validation erreurs]] → [[Persistance - JPA Liquibase PostgreSQL]]. Compare l'API **simulée** de [[React avance]] avec les API Java réelles des TP.

## Étape 4 : architecture et exploitation

[[Architecture - hexagonale et ports]] → [[Metier - commandes stocks transactions]] → [[Fiabilite - outbox inbox jobs]]. Puis [[CI - jobs artefacts et gates]] → [[Securite - secret scan SCA SAST DAST]]. Applique ce chemin à [[Hexa Java]] et [[CI CD DevSecOps]].

## Étape 5 : cloud et coût

[[Azure - ressources regions RBAC Policy]] → [[Cloud - architecture SLA RPO RTO]] → [[FinOps - couts FOCUS allocation]] → [[Bicep - declarer compiler what-if]] → [[Terraform - config plan state]]. Reviens à [[Azure CloudShop]] pour les neuf TP. **Aucun déploiement Azure n'est requis pour lire ce coffre.**

## Reprendre en 30 minutes

Choisis une notion → lis sa fiche → suis le fichier source indiqué → réponds à ses questions → explique le piège sans notes. Note tes questions personnelles dans Obsidian, sans copier de secrets ni d'identifiants d'accès.
